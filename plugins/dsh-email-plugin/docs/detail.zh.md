# 邮件发送插件（QQ 邮箱 / SMTP）

## 配置入口（记住这个就够）

**设置页：<http://127.0.0.1:1461/dsh-email-plugin/settings>**

端口就是 DSH 的 Web 端口（本机为 1461）。打开的页面里填邮箱地址和 SMTP 授权码，点「保存配置」立即生效，不需要重启 DSH。页面还有「测试连接」和「发送测试邮件」按钮。

也可以从对话里让智能体调用 `email_status` 查当前生效的配置和设置页地址。

## QQ 邮箱授权码怎么来

1. 浏览器登录 <https://mail.qq.com>。
2. 打开 **设置 → 账号**（旧版：设置 → 账户）。
3. 找到 **POP3/IMAP/SMTP 服务**，开启 **IMAP/SMTP 服务**。
4. 按提示验证密保后生成 **授权码**（16 位左右，只显示一次）。

服务器用 `smtp.qq.com:465`、加密方式 `SSL/TLS`。授权码是发信密码，**不是 QQ 登录密码**。

## 三个工具

| 工具 | 作用 |
| --- | --- |
| `email_send` | 发信：纯文本 / HTML / 抄送 / 密送 / 文件附件 |
| `email_verify` | 只连接并登录，不发信，用来排查账号 |
| `email_status` | 查看当前生效的配置（密码打码）与设置页地址 |

## 配置存放位置

`C:\Users\<你>\.dsh\email-plugin.json`

页面保存时写这个文件；也可以手动编辑或改用 `DSH_EMAIL_USER` / `DSH_EMAIL_PASS` 等环境变量。所有配置在每次调用时重新读取，改完即生效。

## 安全

- 设置页只接受 127.0.0.1 的请求，写操作要求同源 Origin，跨站请求会被拒绝。
- 授权码不会回显到页面，只保存在本机配置文件里；泄露后到 QQ 邮箱重新生成即可作废。
- 模型只能调用发信工具，看不到、也不需要知道你的授权码。
